# Mobile Shop - Prueba Técnica AMS Solutions

## Comandos

| Comando | Descripción |
|---------|-------------|
| npm start | START - Modo desarrollo |
| npm run build | BUILD - Compilación producción |
| npm run test | TEST - Tests unitarios |
| npm run lint | Verificación de código |

## Estructura de Carpetas

    src/app/
    ├── components/
    │   ├── header/
    │   ├── search/
    │   ├── product-list/
    │   ├── product-item/
    │   ├── product-detail/

## Tecnologías

- **Angular 21** - Framework frontend (standalone components)
- **TypeScript 5.9** - Tipado estático
- **Tailwind CSS 4.2** - Estilos CSS
- **RxJS 7.8** - Programación reactiva
